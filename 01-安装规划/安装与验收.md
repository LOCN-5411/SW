### 三个必须理解的点

**1）为什么 RTX 5060 是"能用"而不是"完美"**
SolidWorks 官方只认证 NVIDIA RTX A/Pro 系列、AMD Radeon Pro 系列这类专业卡。GeForce 是游戏卡，能正常建模、装配、出图，但有一个功能受限：**RealView 真实感图形**（就是那个让模型看起来像金属/塑料的实时渲染）在非认证卡上默认不可用，模型会以普通着色显示。

这对你的目标是**零影响**——毕设和比赛要的是几何正确、能出图、能查干涉，不是画面好看。不要去折腾各种"解锁 RealView 补丁"，那些改注册表/替换 DLL 的做法在比赛机器上有风险，且对交付物没帮助。

**2）内存 24GB 是单条，这是你以后最值得升级的地方**
单条内存 = 单通道。等你做几百个零件的装配体时，会感觉转动视角轻微卡顿。以后如果遇到性能瓶颈，加一条同规格 24GB 内存组双通道是最划算的升级（约 300–400 元），比换任何东西都有效。**现在不用动。**

**3）双显卡是最大的坑，必须装完立刻处理**
你的机器同时有 AMD Radeon 610M 核显和 RTX 5060 独显。Windows 默认可能让 SolidWorks 跑在核显上，症状是：打开就卡、拖动视角幻灯片、甚至闪退。这是零基础自学 SolidWorks 最常见的"装完就废"原因，处理方式见第四节。

## 二、版本怎么选（关键决策，不要随便选最新）

**先确认一件事，再决定装什么：你的学校/团队/比赛要求哪个版本？**

SolidWorks 有一个铁律：

> **高版本存的文件，低版本打不开。** 而且没有官方降级手段。

这意味着如果你的队友用 2024，你装了 2026，你建的零件他打不开，整个协作就断了。毕设和比赛最容易在这里翻车。

**选择优先级：**

1. **如果学校/实验室/队友已经明确了版本 → 就装那个版本，不要自作主张**
2. **如果没人管 → 装比最新版低一到两个版本**，例如最新是 2026 版，就装 2024 或 2025。理由：低版本更稳定、教程和标准件库更齐全、和别人交换文件时兼容性更好
3. **绝对不要**为了"尝鲜"去装最新版，也不要装比学校机房低的版本（机房打不开你的文件）

> ⚠️ **和免费学生版有个硬冲突**：官方免费/付费学生版通常**只提供当前最新版（现在是 2026）**，没有旧版可选。所以**如果队友或机房是 2024/2025，你就不能走"免费学生版"这条路**，必须以学校渠道（借学校授权装旧版）为准。

**版本现状（2026-10-15 核实）**：官方学生商店在售的是 `SOLIDWORKS Design Premium for Students **2026**`，所以当前最新版是 **SOLIDWORKS 2026**。**但"最新"不等于"你该装"** —— 先看上面『选择优先级』第 1 条。

**你要装的是哪个包？** 常见几种，作用不同：

| 类型 | 说明 | 适合你吗 |
|---|---|---|
| 学校正版（教育序列号 / 网络许可 / Student Access） | 学校买的批量授权 | ✅ 最理想，功能最全，版本和机房天然一致 |
| **官方免费学生版**（Design Standard for Students） | **2026-07 起对学生免费**，不再要求 .edu 邮箱 | ✅ **首选主路线**，桌面完整版；文件带教育水印、禁商用 |
| 官方付费学生版（Design Premium for Students） | ¥540.47/年（实测含税），多 Simulation/CAM/Visualize | ⏳ 到阶段 5 需要 Motion 时再考虑 |
| 网上找的"破解版" | 无授权 | ❌ 不建议：比赛/毕设提交有风险，且常捆绑木马 |

**装之前先把序列号/激活方式准备好**，学生版需要在安装后激活。

### 2.3 安装包完整性自检（装之前做，省得装到一半回滚）

- [ ] 有 `sldIM` 目录
- [ ] 总大小在合理范围 —— **完整安装介质通常十几 GB**（随版本与所选产品变化）；**如果只有几百 MB，那多半只是 SP 补丁包，不是主程序**
- [ ] 目录结构完整，不是解压中断的残包
- [ ] 没有大量 0 字节文件
- [ ] 来源若提供过 MD5 / SHA 校验值，做一次校验

```powershell
# 快速自检：把 $p 换成你的安装包路径
$p = 'D:\你的安装包路径'
$f = Get-ChildItem $p -Recurse -File -Force
"大小 GB : {0:N2}" -f (($f | Measure-Object Length -Sum).Sum / 1GB)
"文件数  : {0}"    -f $f.Count
"零字节  : {0}"    -f ($f | Where-Object Length -eq 0).Count
"有 sldIM: {0}"    -f (Test-Path (Join-Path $p 'sldIM'))
```

## 三、安装步骤（按顺序做，别跳步）

### 准备
1. **确认安装包完整**：通常是十几 GB 的 ISO 或多文件夹。检查是否有 `sldIM` 目录（这是安装管理器）
2. **关掉杀毒软件的实时防护**（安装期间），装完再打开——安装管理器会写大量注册表和 DLL，容易被误杀
3. **确保 C 盘和 D 盘都有空间**；建议装到 D 盘，路径避开中文和空格
4. 安装期间**不要**同时跑大型游戏或渲染

### 安装
5. 以**管理员身份**运行安装管理器（右键 → 以管理员身份运行）
6. 安装类型选**单机安装（此计算机）**
7. 序列号：填学校给的 / 学生版激活流程给的
8. **安装位置：改到 D 盘**，例如 `D:\SOLIDWORKS\`（用英文路径，别用中文）
9. 产品选择：
   - **必选**：SOLIDWORKS（主程序）、SOLIDWORKS Toolbox（标准件库，后面装配要用）、SOLIDWORKS Motion（运动仿真，比赛要用）、eDrawings（看图和发给别人）
   - **可选**：SOLIDWORKS Simulation（有限元，晚点再装也行）、Visualize/渲染（对你的目标优先级低）
   - **不要选**：PDM（数据管理，个人学习用不上，而且要多配服务器）
10. 安装过程中如果提示装 **SQL Server Express**（Toolbox 需要它存标准件数据），**允许**。这是正常的，不是捆绑软件
11. 安装过程中如果提示缺少 **.NET / VC++ 运行库**，允许自动安装

### 装完立刻做
12. **重启电脑**（必须，让驱动和注册表生效）
13. 打开 SolidWorks，如果弹出激活向导，按学校/学生版的流程激活

## 四、装完必须做的双显卡设置（不做会卡到你怀疑人生）

### 4.1 让 SolidWorks 强制使用 RTX 5060

**Windows 11 路径：**
1. `设置` → `系统` → `屏幕` → 拉到底 → `显示卡`（或"图形"）
2. 在应用列表里找 `SOLIDWORKS`，或点"浏览"添加：
   - `D:\SOLIDWORKS\SOLIDWORKS\sldworks.exe`（主程序，具体路径按你实际安装位置）
   - 顺便把 `sldworks_fs.exe`（如果存在）也加上
3. 点它 → `选项` → 选 **高性能（RTX 5060）**，不要选"让 Windows 决定"
4. 保存

**NVIDIA 控制面板路径（双保险）：**
1. 桌面右键 → `NVIDIA 控制面板`
2. `管理 3D 设置` → `程序设置` → `添加` → 选中 `sldworks.exe`
3. `首选图形处理器` → **高性能 NVIDIA 处理器**
4. `电源管理模式` → **最高性能优先**
5. 应用

### 4.2 检查是否生效

打开 SolidWorks，然后：
`帮助` → `关于 SOLIDWORKS` → 点 `显示系统信息`（或直接在 SolidWorks 里看 `工具` → `选项` → `性能`）
确认渲染器/显卡显示的是 **NVIDIA GeForce RTX 5060**，而不是 `Radeon 610M` 或 `Microsoft Basic Render Driver`。

**如果显示的是核显或基础渲染器** → 回到 4.1 重做，并且确认笔记本电源模式是"最佳性能"、插着电源适配器（不插电时笔记本会强制降频省电，这是另一个常见"为什么我这么卡"的原因）。

### 4.3 性能设置

`工具` → `选项` → `系统选项` → `性能`：
- ✅ 勾选 **使用软件 OpenGL**：**不要勾**（勾了会强制用 CPU 渲染，暴慢，只在显卡出问题时临时用）
- ✅ 打开 **使用上色预览**（有助于减少误操作）
- `工具` → `选项` → `系统选项` → `显示` → 勾选 **RealView 图形**（如果灰掉了，说明认卡不认，属正常，忽略即可）

## 六、常见安装/启动故障速查

| 症状 | 原因 | 处理 |
|---|---|---|
| 装完启动闪退 | 显卡跑了核显 / 驱动冲突 | 做第四节；把 NVIDIA 驱动用 NVIDIA App 更新到 Studio 版 |
| 打开就提示"无法初始化" | 显卡驱动 | 换装 NVIDIA **Studio 驱动**（比 Game Ready 稳），或临时勾选"使用软件 OpenGL"应急 |
| 界面卡成幻灯片 | 混合显卡 / 没插电源 / 电源模式省电 | 第四节 + 插电源 + 电源模式改"最佳性能" |
| 模型显示异常、有黑面/破面 | 显卡兼容 | 更新驱动；`工具`→`选项`→`性能`→ 调整"细节层次" |
| Toolbox 打不开、提示找不到数据库 | SQL Server Express 没装成功 | 控制面板 → 程序 → 修复 SOLIDWORKS；或手动安装 SQL Server Express |
| 安装到一半报错回滚 | 杀毒拦截 / 安装包不全 / 权限不足 | 关杀毒、管理员运行、重下安装包 |
| 提示许可证无法获取 | 序列号错/网络激活失败 | 检查序列号、临时关防火墙重试激活 |

| 步骤 | 命令 / 方法 | 结果 |
|---|---|---|
| 1 | `nvidia-smi --query-gpu=name,memory.total,memory.used` | RTX 5060 Laptop，总 8151 MiB，**占用 1805 MiB** |
| 2 | `Get-Counter '\GPU Adapter Memory(*)\Dedicated Usage'` | LUID `0xd73d` **占用 1820 MB** |
| 3 | 两数对账 | 1805 ≈ 1820 → **LUID d73d 就是 RTX 5060** |
| 4 | `Get-Counter '\GPU Engine(*)\Utilization Percentage'` 找 sldworks 的 PID | SolidWorks 的引擎实例**只出现在 d73d 上** → 它在独显上 |

> **为什么这么绕**：Windows 的 GPU 计数器只给 LUID（一串十六进制），不给显卡名字。
> 所以要用 `nvidia-smi` 报的显存占用去和计数器对账，才能把 LUID 认出来。
> 这比"打开 SolidWorks 看关于对话框"更硬——那是软件自报，这是系统级实测。

**顺带发现（性能提示）**：`wallpaper64.exe`（Wallpaper Engine 动态壁纸）当时占着 **21% 的 GPU** 和一部分显存。
做大型装配体或渲染时如果觉得卡，**先把动态壁纸暂停**——这是白捡的性能。
