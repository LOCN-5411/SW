# SolidWorks 零基础学习路线图
### 目标：能独立为毕设 / 机械设计比赛 / 机器人项目完成「建模 → 装配 → 出符合国标的工程图」

---

## 0. 先看这一页：你的路线和网上的教程不一样

网上 90% 的 SolidWorks 教程是**软件功能说明书**——把每个命令讲一遍。你跟着看完，还是不会做毕设。原因是它们没有回答一个问题：

> **毕设和比赛真正要交付的是什么？**

答案是一套**图纸 + 三维模型**：加工厂拿着你的图纸能把零件做出来，队友拿着你的装配体能查干涉、能改进。所以真正的能力链路是：

```
看懂一个机构  →  能建出零件  →  能装成机构  →  能出成图纸  →  能改得动
                                  ↑                              ↑
                          查干涉/看运动                  这才是毕设的真实工作量
```

**「能改得动」是分水岭。** 初学者建的模型，改一个尺寸就满屏报错；熟练的人建的模型，改十个尺寸依然正常。区别不在命令记得多不多，而在**草图约束习惯**和**建模顺序**。所以这份路线图把 40% 的精力压在阶段 1。

### 三条铁律（比任何命令都重要）

**铁律一：草图必须"完全定义"（全黑）。**
SolidWorks 的草图有状态：蓝色 = 欠约束（还能拖动），黑色 = 完全定义，黄色/红色 = 过约束或冲突。**从第一天起，不许交出一张蓝色的草图。** 这一条习惯，能帮你省掉后面 80% 的报错。

**铁律二：能用几何关系，就不要用尺寸。**
"这两条线一样长"用【相等】关系，不要标两个 50。区别在哪？以后你要把 50 改成 60，用几何关系只改一处，用尺寸要改两处——漏一处模型就崩。**尺寸是最后手段，不是首选工具。**

**铁律三：先想基准，再动手画。**
每建一个零件，先问自己两个问题：这个零件的**对称中心/回转轴在哪**？我要**从哪个面开始建**？把原点放在有意义的位置（对称中心、回转轴、装配基准面），而不是随便找一个角。这个决定会一直影响到装配和改图。

## 2. 阶段 0：装好并认识界面（2–3h）

**这一步的详细操作在 `E:\SW\01-安装规划\安装与验收.md`，先把它做完再来这里。**

装好之后，花 1 小时熟悉界面，不要急着建模：

- **CommandManager（命令管理器）**：顶部那一排选项卡——`草图`、`特征`、`装配体`、`工程图`、`评估`。所有命令都在这里面，**不需要背菜单位置**

- **前导视图工具栏**：转动、平移、缩放、视图方向
- **属性管理器**：你点任何一个命令，左侧弹出的那个面板
- **右侧任务窗格**：设计库（Toolbox 标准件在这里）、外观、自定义属性

### 必须立刻养成的效率习惯

|---|---|---|
| 旋转视角 | 鼠标中键按住拖动 | 最常用，不会这个寸步难行 |
| 平移 | Ctrl + 中键 | — |
| 缩放 | 滚轮 / Shift + 中键 | — |

**去 `工具` → `自定义` 里把鼠标手势配好，花 10 分钟，省几百次鼠标移动。这是唯一一个"磨刀不误砍柴工"的设置。**

## 3. 阶段 1：草图 —— 你 40% 的功力在这里（8–10h）

**这是全路线最重要的阶段。** 而且它最容易被跳过，因为"画个矩形谁不会"。但请理解一件事：

> SolidWorks 的草图不是"画线"，是**解方程**。你每画一条线，它就有自由度；你每加一个约束或尺寸，就消掉一个自由度。所谓"完全定义"，就是自由度归零、方程有唯一解。

### 3.1 核心概念（必须真正理解，不是记住）

**① 自由度与完全定义**
一条自由直线有 4 个自由度（两端点各 2 个）。理解这个，你就能诊断报错：
- 图形**蓝色、能拖动** → 欠约束，缺约束或尺寸
- 图形**黑色、拖不动** → 完全定义 ✅ 这是目标
- 提示**过定义/冲突** → 约束或尺寸给多了，有冗余
- 状态栏（右下角）会直接写"完全定义"/"欠定义"，**养成每次都瞄一眼的习惯**

**② 几何关系 vs 尺寸**
`草图` → `显示/删除几何关系` 能看到所有约束。常用几何关系及其用途：

| 几何关系 | 什么时候用 | 典型场景 |
|---|---|---|
| 水平 / 竖直 | 线是水平或竖直的 | 几乎所有轮廓 |
| 重合 | 点落在线上/点上 | 连线段、端点在原点 |
| 中点 | 点在线的中点 | 对称结构的中心 |
| 同心 | 两圆同心 | 孔与轴、沉孔 |
| 相切 | 圆与线/圆相切 | 连杆、凸轮、圆角过渡 |
| 相等 | 长度/半径相等 | 多个相同孔、等边结构 |
| 对称 | 两元素关于中心线对称 | **画一半再镜像的关键** |
| 平行 / 垂直 | 线线关系 | 支架、法兰 |
| 固定 | 锁死某元素 | 少用，会破坏参数化 |

**③ 中心线与镜像：对称零件的标准打法**
不要左右各画一半。正确做法是：画中心线 → 画一半 → 用【镜像实体】。这样以后改尺寸，两边自动同步。**这是专业和业余最明显的分界线之一。**

**④ 构造几何线**
中心线、参考圆这类"只用来定位、不参与成形"的线，要设为**构造线**（画完选中 → 勾"作为构造线"）。它们不会影响拉伸结果，但能帮你定位。

**⑤ 基准：原点放哪**
第一个草图的原点位置决定整个零件的基准。规则：
- 对称零件 → 原点放在**对称中心**
- 回转体（轴、法兰、带轮）→ 原点放在**回转轴线上**，用【旋转】而不是【拉伸】
- 有装配基准的零件 → 原点放在**与其他零件的结合面**上

### 3.2 必须掌握的命令

| 分类 | 命令 |
|---|---|
| 绘制 | 直线、圆、圆弧（三点/圆心）、矩形（边角/中心）、**直槽口**、多边形、椭圆、样条曲线 |
| 编辑 | 剪裁实体、延伸实体、等距实体（偏移）、**转换实体引用**、**镜像实体**、线性草图阵列、圆周草图阵列、移动/复制 |
| 约束 | 智能尺寸、添加几何关系、显示/删除几何关系、完全定义草图 |
| 辅助 | 中心线、构造几何线、草图文字、检查草图合法性 |

> 两个被严重低估的命令：**【转换实体引用】**（把已有模型的边投影到当前草图，做配合孔、外形轮廓时必用）和**【等距实体】**（做壁厚、密封槽、流道时必用）。

| 练习 | 名称 | 考核点 |

| 02 | 角度支架轮廓 | 角度尺寸 + 几何关系优先级 |

2. 确认状态栏显示**"完全定义"**，图形全黑

- [ ] 10 张练习草图全部**完全定义**（全黑，状态栏无"欠定义"）

- [ ] 能解释"过定义"是怎么产生的，以及怎么删掉多余约束

### 3.5 这个阶段最容易犯的错（提前避坑）

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用一堆尺寸堆出形状 | 改一个尺寸整个图崩 | 优先用几何关系 |
| 忘点原点 | 草图悬空，整个零件没基准 | 第一个元素就约束到原点 |
| 画完不检查是否全黑 | 埋雷，到装配才炸 | 每次瞄状态栏 |
| 镜像前不画中心线 | 镜像出不来正确结果 | 先中心线，再镜像 |
| 用【移动】命令挪图形 | 破坏约束关系 | 改尺寸/改约束 |
| 一个草图里画所有东西 | 无法单独修改 | 一个特征一个草图 |

## 4. 阶段 2：基础特征建模（10–12h）

### 4.1 核心概念

**① 特征的顺序就是加工顺序**
建模要模拟真实制造过程的思路：先做出毛坯大形体，再切出细节。

**正确顺序：**
```
主体形状（拉伸/旋转）→ 次要形体（凸台/切除）→ 孔 → 倒角 → 圆角（最后）
```

**为什么圆角和倒角必须最后？** 因为圆角要"选中边"来生成。如果你先加圆角，之后再改前面的尺寸，那条边可能消失或变化，圆角就会报错，整个特征树变红。**这个坑几乎每个初学者都踩过，而且症状是"我明明只改了一个尺寸，怎么全红了"。**

**② 特征树 = 历史记录 = 参数化**
双击特征树里的任何一个特征，它的尺寸会显示出来，改完按 Ctrl+B 重建。这就是为什么 SolidWorks 建模"能改得动"。**你改的不是图形，是历史。**

**③ 基准面的选择**
默认有前视、上视、右视三个基准面。选择规则：
- 零件的**主要平面**对齐基准面（通常主视图方向 = 前视基准面）
- 回转体用前视基准面（轴线在其中）
- 需要斜的特征，先建**参考基准面**（`参考几何体` → `基准面`），不要用"3D 草图"硬凑

**④ 常用特征及用途**

| 特征 | 用途 | 典型零件 |
|---|---|---|
| 拉伸凸台/基体 | 由草图沿直线长出实体 | 板、块、支架 |
| 拉伸切除 | 挖掉材料 | 孔、槽、开口 |
| 旋转凸台/切除 | 草图绕轴旋转 | 轴、法兰、带轮、套 |
| 扫描 | 轮廓沿路径移动 | 弹簧、弯管、线缆 |
| 放样 | 多个轮廓过渡 | 异形过渡、手柄、外壳 |
| 抽壳 | 挖空成壳体 | 外壳、盒体、3D 打印件 |
| 筋 | 加强结构 | 支架、铸件加强筋 |
| 圆角 / 倒角 | 过渡 / 去锐边 | 所有零件 |
| 拔模 | 出模斜度 | 注塑件、铸造件 |
| 阵列（线性/圆周/镜像） | 重复结构 | 螺栓孔、齿、散热片 |
| 参考几何体 | 基准面/轴/坐标系 | 定位基础 |

**每个零件的做法要求：**
1. 建模**前**先用一张纸写下你的特征顺序（这一步千万别省，这是"设计"和"瞎画"的区别）
2. 建模完成后，**做改图测试**：挑 3 个尺寸改掉再改回来，确认模型不报错
3. 检查特征树：**能不能说出每一行为什么存在**？有说不出来的行，说明建模思路不清晰，重做
4. 用 `评估` → `质量属性` 看一下体积/质量，估算一下是否符合直觉

## 5. 阶段 3：装配体（8–10h）

### 5.1 核心概念

**① 第一个插入的零件默认"固定"**
这是装配的基准。**不要随便插入第一个零件**，它决定了整个装配体的坐标系。通常选：机架、底板、或最重要的主体零件。

**② 配合 = 约束相对位置，不是"粘在一起"**
初学者以为装配就是"把零件拼起来"，其实是在**定义相对运动关系**。目标不是"完全锁死"，而是**"刚刚够"**：

| 你想要的效果 | 需要几个配合 |
|---|---|
| 零件完全固定 | 3 个（限制 3 个平移 + 3 个转动） |
| **能转动**（车轮、轴、铰链） | 只给【同轴心】，故意留 1 个转动自由度 |
| **能滑动**（导轨、滑块） | 只给【同轴心 + 重合】，留 1 个平移自由度 |
| 齿轮传动 | 【机械配合】→ 齿轮 |

> **关键认知：装配体里"能动"是特性，不是 bug。** 机器人项目里你需要零件能动，才能检查机构行程。全部锁死的装配体是废的。

**② 配合类型**

| 类别 | 配合 | 用途 |
|---|---|---|
| 标准配合 | 重合、平行、垂直、相切、同轴心、距离、角度 | 95% 的日常工作 |
| 高级配合 | 对称、宽度、路径、线性耦合、**限制** | 复杂机构、限位 |
| 机械配合 | 齿轮、齿条、凸轮、万向节、螺旋 | 传动机构 |

**【限制】配合很实用**：比如让滑块只能在 0–50mm 之间运动，用来检查行程。

**③ 干涉检查 —— 比赛和毕设的必备动作**
`评估` → `干涉检查`。这能找出零件之间重叠的部分。**机器人项目里，干涉是灾难性的**，因为加工出来装不上就是几千块钱的废件。

**④ Toolbox 标准件**
`右侧任务窗格` → `设计库` → `Toolbox`：螺栓、螺母、垫圈、轴承、销、键、型材全都有。**不要自己画标准件**，用 Toolbox 拖进来，省时间而且尺寸准确。

> ⚠️ **重要坑**：Toolbox 零件是**本地数据库引用**，不是真实文件。你把装配体拷给别人时，如果对方 Toolbox 配置不同，零件会丢失！**交付时必须用 `文件` → `Pack and Go`（打包）**，把所有引用文件收集到一起。

**⑤ 爆炸视图**
`装配体` 选项卡 → `爆炸视图`，用于说明书和答辩 PPT。毕设答辩时展示爆炸图很加分。

### 5.2 综合练习：装配一个「带座轴承 / 小车轮」

用你阶段 2 建的零件 + Toolbox 标准件：

**方案 A（推荐，最简单）：带座轴承**
- 用练习 10 的轴承座
- Toolbox 里拖入 1 个**深沟球轴承**（按 φ32 内孔配套查标准）
- Toolbox 里拖入 2 个**内六角圆柱头螺钉** M10，配螺母垫圈
- 配合：轴承与轴承孔【同轴心 + 重合】；螺钉与安装孔【同轴心 + 重合】

**方案 B（更贴近机器人）：小车轮组**
- 用练习 09 的带轮改造成轮子 + 练习 08 的轴
- 轴承、轴用卡簧、螺钉
- 配合要求：**轮子必须能转**（只给同轴心，留转动自由度）

**必做动作：**
1. `评估` → `干涉检查`，确认无干涉（如果有，分析是设计问题还是配合问题）
2. 做**运动测试**：拖动能动的零件，看运动是否合理
3. 出一张**爆炸图**
4. `评估` → `质量属性`，看整个装配体的质量和重心位置

### 5.3 阶段 3 验收标准
- [ ] 装配体中至少含 1 个 Toolbox 标准件
- [ ] 干涉检查结果为 0 干涉
- [ ] 指定的运动零件能正确运动（拖动验证）
- [ ] 能出爆炸图
- [ ] 改某个零件的尺寸后，装配体能正确更新
- [ ] 会用 Pack and Go 打包

## 6. 阶段 4：工程图 —— 大多数人跳过，但毕设必须交（8–10h）

**这是自学者最大的短板。** 会建模不会出图，毕设答辩时交不出图纸，直接卡死。而且工程图不难，只是没人教。

### 6.1 核心概念

**① 工程图是从模型"投影"出来的，不是画的**
这是最重要的认知。你在工程图里**几乎不应该用直线工具画任何东西**（除了中心线和局部辅助）。所有视图都是模型的投影，**改模型，图纸自动更新**。如果你手画，改模型时图纸不会变，就等着交图时对不上吧。

**② 中国国标（GB）的关键要求**
- **投影法**：中国用**第一角投影法**（主视图在左上，俯视图在正下方，左视图在正右方）。欧美常用第三角，**注意别搞混**（SolidWorks 图纸属性里可选）
- **图框和标题栏**：要有标准图框（A0–A4）和标题栏（零件名称、材料、数量、比例、图号、设计者、日期）
- **比例**：优先 1:1，其次 1:2、2:1 等标准比例
- **字体**：汉字用长仿宋体（国标），实际用宋体/黑体也能过
- **线型**：粗实线（可见轮廓）、虚线（不可见轮廓）、点划线（中心线）、细实线（尺寸线/剖面线）

**③ 尺寸标注的原则**
- 不要重复标注（同一个尺寸在两个视图里都标）
- 用 `模型项目` 命令**自动导入**模型里已有的尺寸，再手动整理位置——这比手标快 10 倍
- 标注要完整：能唯一确定零件，加工厂不需要来问你
- **公差与配合**：孔轴配合标 `φ32H7/g6` 这种；关键尺寸标公差；一般尺寸按未注公差

**④ 表面粗糙度与形位公差**
- 表面粗糙度符号（Ra 1.6、3.2 等）：标注加工表面要求
- 形位公差（平行度、垂直度、同轴度等）：标注几何精度要求
- **初学者不用标得很专业**，但毕设图纸上应该有这个概念，不要一个都不标

### 6.2 必须掌握的命令

| 分类 | 命令 |
|---|---|
| 图纸 | 新建工程图、图纸格式/模板、图纸属性（比例、投影法）、编辑图纸格式（做自己的标题栏） |
| 视图 | 模型视图、投影视图、**剖面视图**、局部放大视图、断裂视图、辅助视图、旋转剖视图 |
| 标注 | 智能尺寸、模型项目（自动导入）、尺寸公差、**形位公差**、**表面粗糙度符号**、基准符号、中心线、孔标注 |
| 表格 | **材料明细表（BOM）**、零件序号、孔表 |
| 输出 | 打印、导出 PDF、导出 DWG/DXF |

### 6.3 练习

1. **先做自己的图纸模板**：A3 和 A4 各一个，含国标图框 + 标题栏（把学校的校名/学院做进去，毕设直接能用）
2. **出 3 张零件图**：练习 06（L 型支架）、07（法兰盘）、08（阶梯轴）
   - 要求：完整三视图 + 必要的剖视 + 全部尺寸 + 关键尺寸标公差 + 至少标 3 处粗糙度
3. **出 1 张装配图**：阶段 3 的装配体
   - 要求：装配图 + 材料明细表（BOM）+ 零件序号 + 必要的配合尺寸

### 6.4 出图自检清单

> 这一节来自本机 sci 技能库里的 **`mech-undergrad-toolkit`**（机械专业交付规范）。它比通用教程严，但**毕设和比赛的评审就是按这个尺度看的**，建议直接照抄成习惯。

**建模之前：**
- [ ] **关键配合尺寸有权威来源** —— 查标准表（GB/T）、厂商图纸/样本，或实测实物。**不许凭印象给尺寸。**
  - 螺栓孔按 GB/T 标准，不自己编
  - 轴承外径/内径按轴承型号查表
  - 电机/舵机安装孔按厂商图纸或 STEP 文件
  - 3D 打印件的配合间隙按你**自己打印机实测**的公差

**图纸本身：**
- [ ] 视图完整（该有的投影、剖视、局部放大一个不少）
- [ ] **尺寸链不封闭、不矛盾** ← 最容易忽略的一条
  - **不封闭**：不要出现"A+B = C"三个尺寸都标上（加工厂无法判断以哪个为准，这叫封闭尺寸链，是国标明确禁止的）。标注时**留一个尺寸不标**，让它由其他尺寸自然确定
  - **不矛盾**：两个视图里对同一结构标的尺寸必须一致
  - 自检方法：把所有尺寸加起来验算一遍，看是否处处自洽
- [ ] 公差与配合标注合理（孔轴配合标 `φ35H7/g6` 这类；关键尺寸标公差；其余按未注公差）
- [ ] 表面粗糙度（Ra 值，标注需要加工的表面）
- [ ] **材料与热处理**（比如"45 钢，调质 HB220–250"）—— 不写材料，加工厂没法下料
- [ ] 标题栏齐全：**比例、图号、零件名称、材料、数量、设计者、日期**

**出完图之后：**
- [ ] 回到模型改一个尺寸，图纸自动更新且尺寸跟着变（证明是投影不是手画）
- [ ] **保留参数化源文件**（.SLDPRT / .SLDASM），交付时说明生成方式

### 6.5 阶段 4 验收标准
- [ ] 有自己做的 A3/A4 国标图纸模板（含标题栏全部要素）
- [ ] 3 张零件图：通过上面 6.4 的全部图纸检查项
- [ ] 1 张装配图：含 BOM 表和零件序号
- [ ] 改模型后图纸自动更新（6.4 最后一条）
- [ ] 能导出 PDF 和 DWG

## 7. 阶段 5：面向比赛与毕设的专项能力（10–15h）

到这里你已经会"建模→装配→出图"了。这个阶段补的是**项目级**的能力——从"会画零件"到"能设计一个机构"。

### 7.1 自顶向下设计（Top-Down Design）—— 最重要的一项

**自下而上**（你前 4 个阶段的做法）：先建零件，再拼装配体。
**自顶向下**：先定整体布局和关键尺寸，再让零件从布局中"长出来"。

**为什么比赛和毕设必须会？** 因为真实项目里，**整体尺寸是约束**（比如小车的轮距 300mm、底盘高度 50mm），零件尺寸是**由此推导**的。如果自下而上，改一个总尺寸你要手工改几十个零件；自顶向下，改一处全部联动。

**做法：**
1. 在装配体里建一个**布局草图**（Layout Sketch）或**骨架零件**，定义关键轴线、定位点、总尺寸
2. 各零件建模时，用【转换实体引用】引用骨架的边/点
3. 改骨架 → 所有零件联动更新

**先用小项目练手**：做一个"两轮小车底盘"的骨架——定轮距、轴距、轮径、电机位置，然后所有零件引用它。改轮距，整车变形。

### 7.2 运动仿真（SolidWorks Motion）

用于检查机构运动是否合理：行程够不够、会不会卡死、有没有动态干涉、速度曲线是什么样。

- 打开插件：`工具` → `插件` → 勾选 **SOLIDWORKS Motion**
- 在装配体底部切换运动算例：`动画` / `基本运动` / `Motion 分析`
- 常用：给电机加**旋转马达**（定转速），跑几秒，看从动件运动
- 能输出位移/速度/加速度曲线，**毕设里这是很好的分析素材**

### 7.3 质量属性与选型

机器人项目必须算这些：`评估` → `质量属性`
- **质量**：总重多少，会不会超重
- **重心位置**：小车重心太高会翻车
- **转动惯量**：算电机扭矩需要

配合材料设置（给零件指定材料，如 6061 铝合金、ABS），质量属性才准。

### 7.4 交付与协作（这些是真实项目里的血泪教训）

| 事项 | 做法 | 不做的后果 |
|---|---|---|
| 给别人装配体 | `文件` → **Pack and Go** | 对方打开全是缺失零件 |
| 给加工厂 | 导出 **STEP**（三维）或 **DWG/PDF**（图纸） | 加工厂打不开你的 SLDPRT |
| 团队协作 | **统一 SolidWorks 版本号** | 高版本文件低版本打不开，且无法降级 |
| 3D 打印件 | 壁厚 ≥1.2mm（FDM）、留 0.2–0.3mm 装配间隙、螺纹孔按底孔尺寸画 | 打印出来装不上 |
| 版本管理 | 文件名规范：`零件名_版本_日期`，定期另存备份 | 改崩了回不去 |

### 7.5 机器人/比赛项目常用技能清单

- [ ] **标准件库**：Toolbox 里会用型材、螺钉、轴承、销、键
- [ ] **外购件模型导入**：电机、舵机、同步带轮、直线导轨——厂商官网一般提供 STEP 文件，直接导入
- [ ] **铝型材框架**：用型材 + 角件搭机架（Toolbox 或厂商模型库）
- [ ] **同步带/齿轮传动**：用【机械配合】做传动，检查中心距
- [ ] **3D 打印件设计**：壁厚、拔模、圆角、螺栓沉孔、螺母卡槽
- [ ] **干涉检查 + 间隙验证**：运动全程无干涉
- [ ] **出加工图纸**：给机加工件出图，给 3D 打印件出 STL

### 7.6 阶段 5 验收标准
- [ ] 完成一个自顶向下的小项目（骨架 + 零件联动）
- [ ] 用 Motion 跑通一个机构的运动
- [ ] 算过质量属性和重心
- [ ] 完整交付一次：Pack and Go 打包 + STEP 导出 + PDF 图纸

## 9. 现在不要学的东西（很容易被带偏）

网上的 SolidWorks 教程什么都有，但对你当前目标，下面这些**性价比极低**，先别碰：

| 内容 | 为什么先不学 |
|---|---|
| **曲面建模** | 复杂外观设计用的。机器人结构件 99% 用拉伸/旋转/切除就够了。学了不用会忘 |
| **Simulation 有限元分析** | 需要材料力学基础，且毕设里往往不是必需。等你会建模了再说 |
| **PhotoView 360 / Visualize 渲染** | 只影响好不好看，对交付物无影响。想美化，最后花 2 小时学就行 |
| **模具设计 / 钣金 / 焊件** | 除非你的项目确实要用（比如做钣金外壳、焊车架），否则跳过 |
| **PDM 数据管理** | 团队协作到一定规模才需要，个人学习纯负担 |
| **宏 / API 二次开发** | 等你熟练到觉得某件事"重复到烦"的时候再学 |

**判断标准很简单：这个东西能不能帮你把图纸交出去？不能就先放着。**

## 10. 卡住了怎么办（自学者的真实困境）

| 情况 | 处理方式 |
|---|---|
| 草图怎么都不"完全定义" | 用 `显示/删除几何关系` 逐个看；把蓝色元素拖一下，看它往哪动，就知道缺什么约束 |
| 提示"过定义" | 说明约束/尺寸给多了。删掉最新加的那个（通常是重复尺寸） |
| 特征树变红/黄 | 点开看哪个特征失败。通常是前面改了尺寸导致后面的参照丢失。**修最上面的那个，不要从下往上修** |
| 圆角报错 | 圆角半径大于相邻尺寸了，或选中的边在改动后消失 |
| 配合怎么都不对 | 先删掉所有配合，从第一个零件开始一个一个加，每加一个确认位置对不对 |
| 装配体零件丢失 | 用 Pack and Go 重新打包，或 `文件` → `查找相关文件` 重新定位 |
| 完全没思路 | **回到纸上**。把零件的三视图手画一遍，标上尺寸，再回软件。这一步能解决 80% 的"不知道怎么下手" |
| 报错看不懂 | 记下报错原文去搜；SolidWorks 报错信息通常直接说了原因 |

## 11. 学习方法：怎么练才有效

**① 抄图 → 改图 → 默画（三步法）**

- **抄图**：照着图纸建出来。这一步只是入门
- **改图**：改尺寸、改结构，让模型正确变形。**这一步才是真本事**
- **默画**：合上图纸，看着一个实物（水杯、鼠标、自行车零件），自己定尺寸建出来

大多数人只做第一步，所以永远停在"跟着教程能画，自己做就懵"。

**② 每学一个功能，产出一个文件**
不要"看完视频觉得会了"。学完【旋转】，就建一个轴；学完【阵列】，就改一个法兰。**没有文件产出 = 没学会。**

**③ 建立你自己的零件库**
把常用的东西（螺钉、垫片、常用支架、法兰）存到自己的文件夹，用 `设计库` 管理。做项目时直接拖，效率翻倍。

**④ 单个零件不要超过 30 分钟**
如果一个零件建了 1 小时还没成形，说明**思路错了**，不是手速问题。停下来，在纸上重画一遍三视图，重新定特征顺序。

**⑤ 报错时先看特征树，不要瞎点**
特征树就是"病历"。红色的特征、黄色的警告，都在告诉你是哪一步出的问题。养成"先诊断，再动手"的习惯。
