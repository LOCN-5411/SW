# 阶段 5 · 自顶向下设计练习：两轮差速小车底盘

> **对应路线图阶段 5。** 方法论见 `../04-比赛与毕设/比赛毕设作战手册.md` 第二节。
> 这个练习的目标不是"做出一个小车"，而是**学会用骨架驱动整套零件**——
> 做到「改一个总尺寸，整车合理变形」。
>
> **做完能直接用在你的比赛/毕设小车上。**

---

## 一、为什么必须学自顶向下

**自下而上**（阶段 1–4 的做法：先建零件再拼装配体）有一个致命问题：

> 总尺寸一改，你要手工改几十个零件，漏一个就干涉。

而真实项目里，**整体尺寸是设计输入**（比赛有尺寸限制、电机和轮子买来就定了），
零件尺寸是**推导出来的**。改一处就要全线联动——这就是骨架的作用。

---

## 二、设计输入（硬约束，全部放进骨架）

### 坐标系约定

**原点**：驱动轮轴线 × 车体纵轴 × 地面，三者的交点。
**X** = 车长方向（+X 朝万向轮一侧），**Y** = 车宽方向，**Z** = 高度。

### 参数表

| 参数 | 值 | 类型 | 说明 |
|---|---|---|---|
| 轮距 W | **300** | 输入 | 左右驱动轮中心距 |
| 驱动轮轴 ↔ 万向轮中心 L | **130** | 输入 | |
| 车轮直径 D | **φ80** | 输入 | |
| 车轮宽度 | **30** | 输入 | |
| 底盘板厚 t | **5** | 输入 | 铝合金板 |
| 底盘下表面离地 h | **62** | 输入 | 由电机外径推出，见下 |
| 底盘外廓长 | **320** | 输入 | |
| 底盘外廓宽 | **= 轮距 − 60 = 240** | **导出** | 用【方程式】关联 |
| 电机包络体 | **φ37 × 70**，轴 φ6 × 25 | 外购件 | 37GB-520 减速电机 |
| 万向轮 | **φ50**，安装高度 **62** | 外购件 | |

### ⚠️ 这些数字为什么要凑一遍（**这是本练习最该学的东西**）

不要直接抄上面的表。**每一个数都要能说出它的来源**：

**① 底盘高度 h = 62 是怎么来的？**
- 车轮 φ80 → 轮心高度 = D/2 = **40**
- 电机直接驱动轮子 → 电机轴线也必须同高 **Z=40**
- 电机外径 φ37 → 电机最高点 = 40 + 37/2 = **58.5**
- 底盘下表面必须高于电机 → 取 **62**（留 3.5 mm 余量）

> 如果你随手把底盘高度定成 45，**电机会穿进底盘**。这就是"尺寸之间有链条"的实际含义。

**② 底盘宽度为什么是 240？**
- 轮距 300 → 轮心在 Y = ±150
- 车轮宽 30 → 车轮占 Y 135…165
- 底盘半宽必须小于 135 → 取半宽 **120**（即宽 240），留 15 mm 间隙

> 写进骨架时用**方程式**：`底盘宽 = 轮距 − 60`。
> 这样把轮距改成 350，底盘会自动变宽到 290 —— 这才是骨架的价值。

**③ 万向轮中心为什么在 X=130？**
- 底盘长 320（X 从 −160 到 +160）
- 万向轮 φ50 → 占 X 105…155
- 取中心 X=130 → 距底盘前缘 30，且整个轮子都在底盘范围内 ✓

## 三、第 1 步：建骨架零件（**这一步决定成败**）

1. 新建零件，命名 `00_骨架`
2. **在前视基准面**画侧视布局草图：
   - 一条水平线 = **地面**（Z=0）
   - 一条水平线 = **底盘下表面**（标注 = 底盘高 62）
   - 一条水平线 = **轮心线**（标注 = 轮径/2，用方程式关联）
   - 一条竖直线 = **驱动轮轴位置**（X=0，约束到原点）
   - 一条竖直线 = **万向轮中心**（标注 = 130）
   - 全部用**构造几何线**（点"作为构造线"）
3. **在上视基准面**画俯视布局草图：
   - 一条水平线 = **车体纵轴**（过原点）
   - 两条竖直线 = **左右轮心线**（关于纵轴对称，标 **轮距 = 300**）
   - 一个矩形 = **底盘外廓**（长 320、宽 = 轮距 − 60）
   - 万向轮中心点（X=130, Y=0）
4. **不要拉伸。** 骨架是"看不见的骨架"，只是一个承载尺寸的零件
5. **给尺寸改名**：双击尺寸 → 在"主要值"里改成 `轮距`、`底盘高`、`轮径` 这种有意义的名字
6. 存盘。检查：`工具` → `方程式` 里能看到全部命名尺寸与方程式

> **为什么必须命名尺寸**：三个月后你回来改图，看到 `D1@草图1 = 300` 是不知道自己在改什么的。
> 命名尺寸是自顶向下能长期维护的前提。

---

## 四、第 2 步：把骨架放进装配体

1. 新建装配体
2. 插入 `00_骨架` → 右键 → **固定**
3. 骨架决定整个装配体的坐标系，**不要固定别的零件**

---

## 五、第 3–6 步：让零件从骨架里"长出来"

### ① 底盘 `01_底盘`
- 在装配体里新建零件（或独立建零件后引用骨架）
- 草图用【**转换实体引用**】把骨架的**底盘外廓矩形**投影进来
- 【拉伸凸台】**5**
- 四角 R10
- 电机让位：如果电机与底盘干涉，在这里开缺口（改图时优先改骨架，不要直接改零件）

### ② 电机包络体 `02_电机包络`（×2）
- **外购件先用包络体占位**：φ37 圆柱 × 70 长 + φ6 轴 × 25 长
- 电机轴线**引用骨架的轮心线**（【重合】到轮心线所在高度 + 【对称】于左右轮心线）
- 在装配体里用【**镜像**】得到左右两个

> **为什么要用包络体**：厂商 STEP 模型可能一时拿不到，但设计不能停。
> 拿到正式模型后直接【替换零部件】即可。
> **前提**：包络体的关键尺寸（外径、安装孔位、轴径）必须来自**厂商图纸**，不能凭印象。

### ③ 电机座 `03_电机座`（×2）
- 连接底盘下表面与电机
- 孔位引用骨架的轮心位置
- 这是典型的 3D 打印件：壁厚 ≥1.2、孔放公差（M3 过孔画 φ3.4）

### ④ 车轮 `04_车轮`（×2）
- φ80 × 30 宽
- 中心孔 φ6（配电机 D 型轴），加**紧定螺钉孔**（M4）
- 位置由骨架的轮心线决定

### ⑤ 万向轮 `05_万向轮包络`
- φ50 包络体，**安装高度 62**（从安装面到地面）
- ⚠️ 这个尺寸来自你实际买到的万向轮，**是硬约束**

### ⑥ 万向轮安装板 `06_万向轮安装板`
- 连接底盘下表面与万向轮安装面
- 高度 = 底盘高 62 − 安装板厚

---

## 六、第 7 步：装配与干涉检查

- 所有零件引用骨架后，配合应该很少（甚至不需要配合，位置已由骨架决定）
- `评估` → **干涉检查** → 目标 **0 干涉**
- 重点看：电机与底盘、车轮与底盘、万向轮与底盘

---

## 七、第 8 步：改图测试（**本练习的核心验收**）

改骨架，看整车是否合理变形。**三个测试全部通过才算学会自顶向下。**

### 测试 1：轮距 300 → 350
**期望**：底盘宽自动 240 → 290；左右车轮、电机、电机座**对称外移**。
**失败症状**：底盘宽没变，或只有一边的零件移动 → 说明底盘宽没关联方程式、或零件没引用骨架。

### 测试 2：轮径 80 → 100
**期望**：轮心高自动 40 → 50；**电机轴线跟着上移**；底盘高需要你手工确认（因为电机顶会到 68.5 > 62）。
**失败症状**：只有车轮变大，电机没动 → 说明电机轴线没引用轮心线。

### 测试 3：底盘高 62 → 67（**这个测试的意义和别人不一样**）
**期望**：底盘上移，**但万向轮不会变** —— 它是外购件，安装高度是硬约束。
**结果**：车体前倾，前后不平。

> ### 这是本练习最重要的一课
>
> **骨架管得住自制件，管不住外购件。**
>
> 正确做法不是"让万向轮去适应骨架"，而是：
> **把骨架里的 `底盘高` 改成你实际买到的那个万向轮的安装高度。**
>
> 外购件（电机、舵机、轴承、型材、轮子）的尺寸必须以**厂商图纸**为准，
> 反过来**约束**你的骨架。这就是 `mech-undergrad-toolkit` 里那条
> 「关键配合尺寸必须有权威来源」在自顶向下设计里的具体表现。

---

## 八、第 9 步：运动仿真（选做但强烈建议）

1. `工具` → `插件` → 勾选 **SOLIDWORKS Motion**
2. 装配体底部切换算例类型 → **Motion 分析**
3. 给左右车轮各加一个【旋转马达】，转速相同 → 跑 5 秒 → **直行**
4. 把一侧马达反向 → **原地转向**
5. 检查运动全程是否有干涉（静态干涉检查发现不了动态干涉）

**毕设加分项**：导出速度曲线放进说明书。

## 九、验收清单

- [ ] `00_骨架` 存在，两张布局草图**完全定义**，**未拉伸**
- [ ] 骨架里的尺寸**已命名**（`轮距`、`底盘高`…），`工具`→`方程式` 里能看到
- [ ] 底盘宽用**方程式**关联到轮距

## 十、常见错误

| 症状 | 原因 | 处理 |
|---|---|---|
| 改骨架零件不动 | 零件里硬填了尺寸，没引用骨架 | 回到零件草图，用【转换实体引用】重新建立引用 |
| 骨架被拉伸成了实体 | 把布局草图当普通草图用了 | 删除拉伸特征，骨架只保留草图 |
| 方程式不生效 | 写成了固定值而不是表达式 | `工具`→`方程式`，写成 `"底盘宽" = "轮距" - 60` |
| 改轮距后只有一边动 | 只引用了左轮心线，没做对称 | 用【对称】约束或【镜像】 |
| 电机穿进底盘 | 底盘高度没算电机外径 | 见第二节 ①，反推底盘高度 |
| 改底盘高后车体前倾 | 万向轮是外购件，不能跟着变 | **改骨架去适应外购件**，不是反过来 |
| 零件一多就乱 | 没固定骨架 / 固定了错误的零件 | 只固定 `00_骨架` |

你已经会了 SolidWorks 的核心链路。接下来：

1. **把这个底盘做成你自己的项目**——换成你实际买到的电机和轮子，重新算一遍尺寸链
