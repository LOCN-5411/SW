# 阶段 4 · 工程图：模板规格与出图要求

> **对应路线图阶段 4。** 这是自学者最大的短板，也是毕设答辩的硬通货。
> 交付物：**A3/A4 国标模板各一个 + 3 张零件图 + 1 张装配图（含 BOM）**。

---

## 一、先记住一件事

> **工程图是从模型投影出来的，不是画出来的。**

你在工程图里**几乎不应该用直线工具画任何东西**（中心线和标注除外）。所有视图都是模型的投影，**改模型，图纸自动更新**。
如果你手画，改模型时图纸不会跟着变——交图时对不上，这是致命错误。

---

## 二、自己动手做图纸模板（先做这个，别跳过）

### 第 1 步：新建工程图并进入图纸格式编辑
1. `新建` → `工程图` → 图纸格式选 **A3（420×297，横向）**
2. 在图纸空白处**右键** → **编辑图纸格式**
   （此时边框变蓝，表示你在编辑"格式"而不是"图纸内容"）

### 第 2 步：画图框
用【矩形】+【等距实体】画内框，或用草图直线画：
- **装订边 a**：左侧边距（见下方"尺寸来源"说明）
- **其余三边 c**：上、右、下边距
- 选内框四条线 → 右键 → `线粗` → 设为 **粗实线**（约 0.7 mm）

### 第 3 步：画对中符号
四边中点各画一条 **5 mm 的粗实线**，从纸边界画入图框内。

### 第 4 步：画标题栏
- 尺寸 **180 × 56 mm**，紧贴**右下角内框线**
- 外框用粗实线，内部隔线用细实线
- 需要的字段：**图名、图号、材料、数量、重量、比例、设计、审核、日期、单位名称**

### 第 5 步：加文字
用 `注释` 工具在对应的格子里写字（图名、材料、比例…）
- 字体：**仿宋** 或 **宋体**（国标要求长仿宋，实际宋体也能过）
- 字号：标签用 **3.5**，图名用 **5～7**
- **一张图最多 3 种字号**，不要大大小小一堆

### 第 6 步：设置投影法（关键，别漏）
`工具` → `选项` → `文档属性` → `工程图` → 勾选 **第一角投影**
（中国用第一角。改成第三角的话，俯视图会跑到上方、左右视图会互换，图纸直接不合格）
也可以双击图纸 → 图纸属性 → 改投影类型。

### 第 7 步：存成模板
1. `文件` → `保存图纸格式` → 存为 **`.slddrt`**（只存图框+标题栏）
2. `文件` → `另存为` → 类型选 **工程图模板 `.drwdot`**（存模板，含文档属性设置）
3. **A4 同样做一遍**

> 以后新建工程图直接选你自己的模板，图框标题栏自动就有——不用每次重画。

## 三、图框与标题栏的尺寸来源（**请核对，我没拿到标准原文**）

配套文件里有一个生成器：**`make_gb_frames.py`**，它输出 DXF 和预览图。

### ⚠️ 诚信声明

| 项 | 值 | 可信度 |
|---|---|---|
| 标题栏尺寸 | **180 × 56**（GB/T 10609.1） | 常用值，把握较大 |
| 图框装订边 a | **25** | ⚠️ **两种说法冲突**：我记忆与多数教材表格是 25，一份第三方资料写 20 |
| 其余三边 c | **5**（A3/A4） | 多数教材表格 |

**我联网抓 GB/T 14689 原文时被网络拦截，没有拿到官方数字。** 所以：
- 脚本把 `a` 和 `c` 做成了顶层参数（`BIND_MARGIN`、`OTHER_MARGIN`），改两行重跑即可
- **请你对照教材或学校发的图纸模板确认这两个数**，再决定用哪个
- 另外：脚本生成的标题栏是**实用简化版**，不是 GB/T 10609.1 的完整分区图（完整版还含更改区、附加栏）。学生图纸够用，但你要知道它是简化版，答辩被问到别说是完整国标

### 怎么用生成的 DXF

```
E:\SW\05-阶段实战练习\GB-A3横.dxf
E:\SW\05-阶段实战练习\GB-A4横.dxf
E:\SW\05-阶段实战练习\preview\GB-A3横.png   ← 先看这个
```

**⚠️ 用法是"核对答案"，不是"抄近路"：**

1. **先按第二节自己画一遍** —— 这是阶段 4 的学习内容
2. 画完再打开 `preview\GB-A3横.png` 对照：边距对不对、标题栏位置对不对、格子分得对不对
3. 有出入就回 SolidWorks 改

> 直接导入 DXF 确实能省两小时，但你就跳过了"图框怎么定位、标题栏怎么分区、线宽怎么分"这些必须会的判断。
> 等你**自己做过一次**之后，再导入 DXF 当模板用是完全合理的。

**导入方法**（如果你决定用）：
`文件` → `打开` → 选 DXF → 进入图纸格式编辑状态 → `插入` → `DXF/DWG`
（DXF 里只有线，标题栏文字要自己在 SolidWorks 里加）

## 四、出图规范（三个零件图 + 一个装配图）

### 通用要求

| 项 | 要求 |
|---|---|
| 视图 | 完整：主视图 + 必要投影视图 + 必要的剖视/局部放大 |
| 中心线 | 用 `注释` → `中心线`/`中心符号线` 自动插入，不要手画 |
| 尺寸 | 用 **`模型项目`** 自动导入模型里已有的尺寸，再拖到合适位置——**不要手标**（手标会重复） |
| 尺寸链 | **不封闭、不矛盾**（见路线图 6.4 自检清单） |
| 公差 | 关键配合标 `φ32H7` 这类；一般尺寸按未注公差 |
| 形位公差 | 至少标 1～2 处（如底面的平行度、孔的垂直度） |
| 表面粗糙度 | 至少标 3 处（加工面 Ra 3.2 / 1.6） |
| 材料与热处理 | 标题栏必须写（如 `HT200` / `45钢 调质`），不写加工厂没法下料 |
| 比例 | 优先 1:1；需要缩放时用标准比例 1:2、1:5、2:1 |

### 三张零件图

| 零件 | 图纸 | 重点练什么 |
|---|---|---|
| 练习 06 L 型支架 | 主视图 + 俯视图 + 左视图 | 三视图布置与"长对正、高平齐、宽相等" |
| 练习 07 法兰盘 | 主视图 + 全剖视图 | 剖视与剖面线；PCD 与圆周阵列孔的标注 |
| 练习 08 阶梯轴 | 主视图 + 键槽处断面 | 移出断面；退刀槽与倒角的标注 |

### 一张装配图

用阶段 3 的带座轴承装配体：
- 装配图（可以是全剖或半剖，看需要）
- **材料明细表（BOM）**：`注释` → `表格` → `材料明细表`
- **零件序号**：`注释` → `自动零件序号`，序号要与 BOM 对应
- 标出关键配合尺寸（如轴承孔 φ32H7）

## 五、验收清单

做完逐条打勾（与路线图 6.4/6.5 一致）：

**模板**
- [ ] A3 和 A4 模板各一个（`.drwdot`），图框与标题栏正确
- [ ] **投影法设为第一角**（这条最容易漏）
- [ ] 标题栏字段齐全：图名、图号、材料、数量、比例、设计、审核、日期、单位

**图纸**
- [ ] 3 张零件图 + 1 张装配图
- [ ] 视图完整，无手画的轮廓线
- [ ] 尺寸无重复、无矛盾、**尺寸链不封闭**
- [ ] 有公差、形位公差、表面粗糙度、材料
- [ ] 装配图有 BOM 表和零件序号

**关键测试（最重要）**
- [ ] 回模型改一个尺寸 → 图纸**自动更新**且尺寸跟着变
      （证明是投影不是手画；这条不过，说明你在图纸上手画了东西，必须回炉）
- [ ] 能导出 PDF 和 DWG

## 六、常见错误

| 症状 | 原因 | 处理 |
|---|---|---|
| 改模型图纸不变 | 在图纸上手画了线 | 删掉手画内容，改用模型视图 |
| 俯视图跑到主视图上方 | 投影法设成了第三角 | 文档属性 → 工程图 → 改第一角 |
| 每次新建都要重画图框 | 没存 `.drwdt`/`.drwdot` 模板 | 做完模板后保存，以后直接调用 |
| 尺寸标重复了 | 手标 + 模型项目导入，两套 | 只用【模型项目】，手标只补模型里没有的 |
| 剖视图剖面线方向不对 | 剖面线角度/间距没设 | 选中剖面视图 → 剖面线属性 → 调角度与间距 |
| 导出 DWG 后字体变了 | 字体未映射 | 导出对话框里做字体映射，或图纸统一用宋体 |
