# 比赛 / 毕设作战手册

> 面向你的具体目标：**机械设计比赛、机器人项目、毕业设计**。
> 这份文档不讲命令，讲**项目里真正会让你翻车的东西**。每一条都是花过钱或返过工的教训。

---

## 一、先明确：这三类项目要的东西不一样

| 项目类型 | 核心难点 | 图纸要求 | 额外要求 |
|---|---|---|---|
| **机械设计比赛** | 机构能不能动、会不会干涉、重量 | 关键件出图，其余可只给三维 | 运动仿真、BOM、成本估算 |
| **机器人项目** | 装配可行性、公差累积、外购件匹配 | 加工件必须出图，3D 打印件出 STL | 干涉检查、质量/重心、电机选型 |
| **毕业设计** | 说明书 + 图纸的完整性和规范性 | **全套图纸**，含装配图 + BOM | 答辩 PPT、计算说明书 |

**共同点**：都不是"建个漂亮模型就完事"。评委/队友/加工厂关心的是**能不能做出来、能不能装上、改了能不能跟着改**。

## 二、自顶向下设计（Top-Down）—— 项目级的第一步

### 为什么必须会

**自下而上**（你前 4 个阶段的做法：先建零件再拼装配体）的致命问题：

> 总尺寸一改，你要手工改几十个零件，漏一个就干涉。

真实项目里，**整体尺寸是硬约束**，零件尺寸是推导出来的。比如"小车轴距 260mm、轮距 300mm、离地间隙 40mm"——这是设计输入，不是自己定的。

### 具体做法

**第 1 步：建骨架（Skeleton）**

在装配体里新建一个零件，命名为 `00_骨架`，在它的前视基准面上画**布局草图**：

```
- 一条水平线 = 轴距轴线（标 260）
- 两条竖直线 = 车轮轴线位置（标 轮距 300）
- 几条定位点 = 电机安装中心、电池仓边界、传感器位置
- 关键高度 = 离地间隙 40
```

**这个草图不用拉伸，只用它的线和点。** 全部尺寸标好、完全定义。

**第 2 步：所有零件引用骨架**

建每个零件时：
1. 在装配体里编辑零件（或先插入骨架零件再引用）
2. 草图里用【转换实体引用】把骨架的线/点投影进来
3. 后续所有尺寸都基于这些投影

**第 3 步：改骨架验证**

把轴距从 260 改成 300，重建。**所有零件应该跟着变，且不报错。** 如果报错了，说明某处没引用骨架而是硬编码了尺寸——回去修。

### 判断你有没有做对

一个测试就够了：**改骨架上的一个数，整个装配体是否合理变形？**
- 是 → 你做对了，这是比赛和毕设里最省命的能力
- 否 → 你只是"用了一个叫骨架的文件"，实际还是自下而上

### 什么时候不要自顶向下

- 零件之间**没有强尺寸耦合**（比如一堆独立的 3D 打印支架）→ 自下而上更简单直接
- 一次性、不会改的设计 → 不值得搭骨架

**别教条化。** 自顶向下是"要改图时"的保险，不是必须的仪式。

## 三、配合尺寸必须有权威来源

这是 `mech-undergrad-toolkit` 里的一条硬性规范，我认为它是**机器人项目最容易出人命的地方**：

> **建模前先确认配合尺寸的权威来源（标准件表、厂商图纸、量得的实物尺寸），不要凭印象给 25.4/25.0 这类关键尺寸。**

### 什么算"权威来源"

| 对象 | 权威来源 | 不要这么做 |
|---|---|---|
| 螺栓/螺母/轴承 | **GB/T 标准表**（Toolbox 内置的就是标准数据） | 凭印象画个 M6 孔 |
| 电机/舵机 | **厂商官网的图纸或 STEP 文件** | 用卡尺量外壳然后四舍五入 |
| 同步带轮/齿轮 | 厂商样本（含节圆直径、中心距） | 按外径估 |
| 型材 | 厂商型材截面图（欧标 2020/3030/4040） | 按外形尺寸画方块 |
| 3D 打印件配合 | **实测你打印机的公差**（打印一个测试件量） | 假设和图纸一模一样 |

### 具体案例：一个轴承孔的公差

你要在轴承座里装一个 6202 深沟球轴承（外径 35mm）。

- ❌ 画 `φ35.00` 精确配合 → 加工出来**装不进去**（机加工必然有公差，理论上等于尺寸的孔实际做不出来）
- ✅ 画 `φ35 +0.027/0`（相当于 H7）→ 有间隙，能装，还能选过渡配合

**"图纸上写 35 就做 35" 是不存在的。** 你在图纸上写的是**公差带**，不是精确值。

### 3D 打印的孔要放大

FDM 打印的孔会收缩/塌陷，实际孔径比设计值小 0.2–0.4mm。
- 需要 M3 螺钉**穿过**的孔：画 `φ3.4`（不是 φ3）
- 需要 M3 螺钉**自攻**进塑料：画 `φ2.7`
- 需要**热熔铜螺母**：按铜螺母厂商给的孔径画（通常 φ4.2 for M3），**这是最可靠的做法**

## 四、干涉检查与运动验证（机器人项目的命门）

### 干涉检查

`评估` → `干涉检查` → 全选零件 → 计算。

**三个必须检查的时机：**

1. **装配完成后**：静态干涉（零件重叠）
2. **运动过程中**：动态干涉——这是静态检查发现不了的！必须配合 Motion 或手动拖动到极限位置再查
3. **交付前**：最后一次确认

**发现干涉怎么办：**
- 先判断是**设计问题**还是**配合问题**（配合给错了会让零件跑到错误位置产生假干涉）
- 设计问题：改零件尺寸，**优先改骨架或引用关系**，不要直接改零件（会破坏自顶向下链）

### 运动验证

不要只做静态装配。**把机构拖到两个极限位置**，看：
- 有没有卡死
- 连杆会不会出现死点
- 零件会不会撞在一起
- 行程够不够

用 `评估` → `测量` 量关键行程距离。

### 用 Motion 做严谨验证

`工具` → `插件` → 勾选 **SOLIDWORKS Motion**，装配体底部切换算例类型：

| 类型 | 用途 |
|---|---|
| 动画 | 只做视觉动画，不计算物理 |
| 基本运动 | 考虑质量，算运动学 |
| **Motion 分析** | 完整动力学，能出位移/速度/加速度/力曲线 |

给驱动件加【旋转马达】或【线性马达】，设定转速/速度，跑 5–10 秒，看从动件是否正常。

**毕设加分项**：把速度/加速度曲线导出，放进说明书做机构分析。

## 五、数字交付：打包、导出、协作

### Pack and Go（最重要）

`文件` → `Pack and Go` → 打包成文件夹或 ZIP。

**必须用它的场景：**
- 把装配体发给队友
- 交给老师/评委
- 换电脑继续做
- 存档备份

**为什么必须**：装配体文件（.SLDASM）里**不包含**零件数据，只记录路径引用。直接拷 .SLDASM 给别人 → 对方打开全是"找不到零件"。而 Toolbox 标准件更是**本地数据库引用**，不打包必然丢失。

**勾选项建议**：
- ✅ 包含 Toolbox 零件（关键！否则对方没配 Toolbox 就丢件）
- ✅ 包含工程图
- ✅ 包含外观/贴图
- ✅ 保存到 ZIP

### 导出格式对照

| 给谁 | 导出什么 | 怎么做 |
|---|---|---|
| 机加工厂 | **STEP**（.step/.stp）+ PDF 图纸 | `文件`→`另存为`→STEP；图纸导出 PDF |
| 3D 打印 | **STL** 或 3MF | `文件`→`另存为`→STL，**检查单位是 mm** |
| 激光切割 | **DXF** | 从工程图或面导出 DXF |
| 队友（也用 SolidWorks） | Pack and Go 的 ZIP | 见上 |
| 队友（用别的 CAD） | STEP + 图纸 PDF | 通用格式，任何 CAD 都能读 |
| 老师看模型 | **eDrawings**（.exe 或 .easm） | `文件`→`另存为`→eDrawings，对方不用装 SolidWorks 也能转着看 |

> ⚠️ **STEP 是"哑"格式**：导出后没有特征树、没有参数、没有配合。对方只能看和加工，不能改。**所以源文件（.SLDPRT/.SLDASM）必须自己留好** —— 这也是 `mech-undergrad-toolkit` 里"保留参数化源文件"的要求。

### 团队协作规范（现在定好，后面省事）

| 事项 | 规范 |
|---|---|
| **版本** | **全队统一 SolidWorks 版本**（高版本文件低版本打不开，无解） |
| 文件名 | `零件名_v2_20261015.SLDPRT`，不要用 `新建零件1`、`最终版`、`最终版2`、`真最终版` |
| 文件夹 | 按装配体分文件夹，每个装配体一个 Pack and Go 备份 |
| 备份 | 每天收工 Pack and Go 一次存档 |
| 谁改什么 | 分工到零件级，不要两个人改同一个装配体 |

## 六、加工方式的现实约束

**设计的时候就要想"这东西怎么做出来"。** 这是学生和工程师最大的差距之一。

| 工艺 | 适合 | 设计约束 | 单件成本（参考） |
|---|---|---|---|
| **3D 打印（FDM）** | 支架、外壳、非受力件、快速迭代 | 壁厚≥1.2mm、悬垂<45°、孔要放大、螺纹不可靠 | 几元–几十元 |
| **3D 打印（SLA/树脂）** | 精细件、外观件 | 脆、怕冲击、尺寸稳定 | 几十–上百元 |
| **CNC 加工** | 受力件、精度件、铝件 | 内直角做不出来（要有圆角）、深孔难、成本高 | 几十–几百元 |
| **激光切割** | 平板件、机架板 | **只能切通孔，做不出台阶/沉孔**（要另配沉头螺钉） | 按面积算，便宜 |
| **铝型材** | 机架、框架 | 用标准型材 + 角件，**不要自己设计截面** | 按米算 |
| **标准件** | 螺钉、轴承、销、卡簧 | **不要自己画**，直接买 | 很便宜 |

**几条血泪规则：**
1. **能用标准件就别自己设计** —— 自己设计的非标件要单独加工，贵、慢、容易错
2. **CNC 件的内直角要加圆角**（刀具是圆的，铣不出直角内角，除非用电火花）
3. **激光切割件做不出沉孔**，要么改成沉头螺钉 + 另配，要么改用 CNC
4. **薄壁件会变形**：长条形零件 CNC 加工会翘，加筋或改厚
5. **第一批只做 1 件验证**（3D 打印最好），确认装配无误再批量

## 七、翻车点清单（提前避开）

按"翻车概率 × 后果严重度"排序：

| # | 翻车点 | 后果 | 预防 |
|---|---|---|---|
| 1 | **团队 SolidWorks 版本不一致** | 文件打不开，无法协作 | 开工前统一版本 |
| 2 | **关键配合尺寸凭印象** | 零件装不上，重做重买 | 查标准表/厂商图纸/实测 |
| 3 | **静态装配没干涉，一动就撞** | 机构卡死 | 拖到极限位置 + Motion 检查 |
| 4 | **交付只给 .SLDASM 没打包** | 对方打不开 | 一律 Pack and Go |
| 5 | **没备份，改崩了回不去** | 几天工作没了 | 每天 Pack and Go 存档 |
| 6 | **图纸尺寸链矛盾/封闭** | 加工厂做不出来或做错 | 出图后逐条核尺寸链 |
| 7 | **3D 打印孔没放公差** | 装不上，磨/钻 | 按第三节的孔径表 |
| 8 | **Toolbox 件丢失** | 装配体残缺 | Pack and Go 勾选包含 Toolbox |
| 9 | **总装尺寸超限**（比赛有尺寸/重量限制） | 直接失去资格 | 骨架里就定死总尺寸，随时量 |
| 10 | **圆角/倒角加太早** | 改尺寸后特征树全红 | 圆角倒角放最后 |

## 八、毕设答辩要准备什么

评委看的不是"你模型建得多漂亮"，是**"你设计的东西是否可信"**。

### 必备材料

- [ ] **装配图**（含 BOM 明细表、零件序号、关键配合尺寸）
- [ ] **零件图**（关键件全套，含公差、粗糙度、材料、热处理）
- [ ] **爆炸图**（展示装配关系）—— 视觉冲击力强，加分
- [ ] **运动仿真截图/曲线**（证明机构能动、行程够）
- [ ] **质量属性**（总重、重心位置）—— 如果项目有重量/稳定性要求，这是硬指标
- [ ] **干涉检查结果**（截图证明无干涉）
- [ ] **三维动画或视频**（`SolidWorks` 的 Motion 导出 AVI，或转成 GIF 放 PPT）

### 说明书里 CAD 相关章节要写的

1. 设计方案的确定过程（为什么这么设计）
2. 关键零件的强度/选型计算（**公式 + 代入过程 + 结果，带单位**）
3. 三维建模与装配过程
4. 干涉检查与运动仿真结果
5. 图纸（装配图 + 零件图）

> 按 `mech-undergrad-toolkit` 的规范：**每个数值都要带单位、图纸检查项要逐条过、仿真要给可信度证据**（构建过程、参数来源、与理论/实测的对照）。毕设说明书最容易扣分的地方就是"只给结果不给过程"和"仿真当实验"。

### 答辩 PPT

用 `scientific-slides` 技能来搭结构和排版。CAD 部分建议页序：

```
设计需求 → 总体方案 → 三维模型总览 → 关键机构运动分析 →
干涉检查 → 关键零件设计（图 + 计算）→ 图纸 → 实物/打印验证 → 结论
```

## 九、现在就该养成的四个习惯

1. **每建一个零件，先想它怎么加工出来** —— 想不出来就说明设计有问题
2. **每天收工 Pack and Go 一次** —— 花 30 秒，省几天
3. **改图前先想"这个改动会影响哪些引用"** —— 特征树从上往下看
4. **关键尺寸标出处** —— 在图纸或说明书里写"依据 GB/T 276—2013"或"依据厂商样本 P12"
